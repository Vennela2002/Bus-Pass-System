# Bus-Pass-System

Description and Priority The bus pass system keeps track of buses, seats, prices, and reservations. It also keeps track of bus passes for trips inside a certain city. Of course, this initiative is a high priority because travelling across cities in buses without previous bookings is quite difficult. It simplifies the procedure of purchasing city bus tickets while also lowering the financial load.

Stimulus/Response Sequences

• Register/Login to the website

• Modify user’s profile

• Recharge one’s wallet using card or UPI if not recharged

• Apply for a city bus pass and submit the documents

• Search for buses between two cities

• Displays a detailed list of available buses

• Book a ticket on a particular bus.

• Cancel an existing reservation

• Rate your travel and provide any useful feedback
